# 家庭記帳 LINE 機器人

把機器人加進家人的 LINE 群組，傳「午餐 120」就會自動記到 Google 試算表。**完全免費，不用申請任何 AI 金鑰**；加上免費的 Gemini 金鑰後還能隨口說、拍發票。

## 主要功能

| 功能 | 說明 | 範例 |
|---|---|---|
| 💰 智慧記帳 | 透過自然語言記錄消費，一次可記多筆，可加日期與分類 | `午餐 120`、`昨天 中油 1200`、`加油 1200、停車 60`、`掛號 150 醫療` |
| 📷 AI 發票辨識 | 從發票、收據圖片中辨識店名、日期與金額（需要 Gemini 金鑰） | 直接傳照片 |
| 🔎 消費查詢 | 查看消費紀錄、總支出、各分類與各家人花費、最高單筆消費 | `本月`、`本月 餐飲`、`全聯花多少`、`本月 明細` |
| 📊 消費分析 | 分析今天、本週、本月、上月的支出，平均每天花多少，和上個月同期比較 | `分析`、`本週分析`、`上月分析` |
| 🔥 消費洞察 | 找出最高支出類別、最高單筆、最高單日與增加最多的分類 | 包含在「分析」的回覆裡 |
| ✏️ 修改消費 | 修改金額、分類與消費項目（只能改自己記的帳） | `修改 150`、`修改 交通`、`修改 品項 早餐`、`午餐改成150` |
| 🗑️ 刪除消費 | 刪除最近一筆，或指定品項、日期、金額刪除 | `刪除`、`刪除 午餐`、`刪除 昨天 停車 60` |
| 🔔 訂閱管理 | 建立與查詢房租、水電、Netflix 等週期性支出，到期自動記帳 | `固定支出`、`固定支出 Netflix 390 每月15號`、`固定支出 刪除 Netflix` |
| ⏰ 扣款提醒 | 扣款前一天在家庭群組提醒，也可以查詢近期即將扣款的項目 | `近期扣款`、`最近要繳什麼` |
| 🛡️ AI 錯誤處理 | Gemini 忙線（503）或額度用完（429）時自動重試，仍失敗就改用規則辨識照樣記帳，並給中文提示 | 自動 |

這些功能都在同一個 LINE Bot 裡，傳 `說明` 或 `選單` 會出現快速選單按鈕（本月花費、本月明細、分析、固定支出、扣款提醒…），點一下就能用。按鈕送出的都是固定指令，不會用到 AI 額度。

### 細節

- **日期**：`昨天`、`前天`、`10/8`、`10月8日`、`2026-10-08`；沒寫就是今天。
- **分類**：餐飲、交通、日用品、醫療、育兒，以及其他（在 `gas/Config.gs` 修改）。
- **查詢期間**：`今天`、`昨天`、`本週`、`本月`、`上月`、`今年`。
- **分析的比較方式**：和**上個月同一段日期**比（10/1～10/9 對 9/1～9/9），上一期沒有資料時不硬算百分比；固定支出和日常花費分開看。
- **總計行**：多筆訊息最後的 `金額 1125`、`合計 1125` 只拿來核對，不會重複記帳。
- **群組裡的閒聊不會被誤記**：金額要放在最後；`取消聚餐`、`計畫改成明天` 這類句子不會被當成刪除或修改。

分類是用**關鍵字**判斷的，例如「全聯」→ 日用品、「7-11」→ 餐飲、「中油」→ 交通。判斷不出來的歸到「其他」，也可以在試算表的「關鍵字」工作表自己新增。

架構：LINE → Google Apps Script → Google 試算表，全部免費。

## 設定步驟（約 30 分鐘，建議用電腦）

### 1. 建立 LINE 機器人

LINE 現在不能直接在 LINE Developers 建立 Messaging API channel，要**先建立官方帳號，再啟用 Messaging API**。

1. **建立 LINE 官方帳號**：到 [LINE Official Account Manager](https://manager.line.biz/) 用 LINE 帳號登入，按「建立 LINE 官方帳號」填寫表單（名稱例如「家庭記帳」；業種隨意選，例如「個人」）。
2. **啟用 Messaging API**：在官方帳號後台右上角 **設定 → Messaging API → 啟用 Messaging API**。手機版後台可能沒有這個選項，請用電腦，或在瀏覽器選單選「要求電腦版網站」。
   - 選擇或建立一個 **Provider**（例如「我的家」）。Provider 選定後**不能更改**。
   - 隱私權政策、服務條款網址可以留空，按確定。
3. **調整回應設定**：同一個後台的 **設定 → 回應設定**：
   - **聊天**：關閉
   - **自動回應訊息**：關閉
   - **Webhook**：開啟
4. **允許加入群組**：**設定 → 帳號設定 → 功能切換**，把「加入群組或多人聊天室」改成允許。
5. **取得權杖**：到 [LINE Developers](https://developers.line.biz/console/) 用同一個 LINE 帳號登入，點剛剛的 Provider，再點官方帳號對應的 channel：
   - **Messaging API** 分頁最下方 **Channel access token (long-lived)** 按 **Issue**，複製權杖。權杖等同密碼，不要給別人看。
   - 同一頁掃 QR code，把機器人加為好友。
6. （選填）在 **Basic settings** 分頁最下方複製 **Your user ID**（U 開頭），第 2 步會用到。

### 2. 建立試算表和 Apps Script

1. 開一個新的 [Google 試算表](https://sheets.new)，命名為「家庭帳本」。
2. 選單 **擴充功能 → Apps Script**。
3. 打開本專案的 [`dist/家庭記帳.gs`](dist/家庭記帳.gs)，按右上角的複製按鈕複製全部內容。
4. 回到 Apps Script 編輯器，把預設檔案 `程式碼.gs` 的內容**全部刪掉**，貼上剛剛複製的內容，按 💾 儲存。
5. 「專案設定（齒輪）→ 指令碼屬性」新增：

   | 屬性 | 值 |
   |---|---|
   | `LINE_CHANNEL_ACCESS_TOKEN` | 第 1 步的 Channel access token（一整串，中間不能有空格） |
   | `LINE_BOT_USER_ID` | （選填）第 1 步的 Your user ID |

6. 回到編輯器，上方函式選 `setup`，按 **執行**，依指示授權（會出現「Google 尚未驗證這個應用程式」，按「進階 → 前往（不安全）」，這是你自己的程式所以沒關係）。試算表會多出「帳本」、「關鍵字」、「固定支出」三個工作表，並建立每天早上 8 點檢查固定支出的排程。

### 3. 部署並連上 LINE

1. Apps Script 右上角 **部署 → 新增部署作業**，齒輪選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
2. 部署後複製 **網頁應用程式網址**（`https://script.google.com/macros/s/.../exec`）。
3. 回到 LINE Developers 的 **Messaging API** 分頁：
   - **Webhook URL** 貼上網址，按 Update
   - 打開 **Use webhook**
   - 按 Verify 有時會顯示 302 錯誤，這是 Apps Script 的轉址造成的，**不影響實際使用**
4. 私訊機器人 `午餐 120` 測試。成功後把機器人邀進家庭群組。

> ⚠️ **之後更新程式碼**：貼上新版程式後，先執行一次 `setup`（新功能可能需要新的授權），再到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」，網址不會變。

## 固定支出

可以直接在 LINE 管理，也可以改試算表的「固定支出」工作表。

**用 LINE：**

| 傳送 | 效果 |
|---|---|
| `固定支出 Netflix 390 每月15號` | 新增；同名的項目則更新 |
| `固定支出 房租 16000` | 只改金額，其他不變 |
| `固定支出 電費 不固定 每2個月 20號` | 金額不固定，只提醒 |
| `固定支出 刪除 Netflix` | 刪除 |
| `我有哪些固定支出？`、`房租什麼時候繳` | 查看 |

沒說幾號時，扣款日用今天的日期，從下個月開始。開啟 AI 時也可以直接說「我每個月訂 Netflix，月費 390，15 號扣款」。

**用試算表：** 每列一個項目（`setup` 會先放好房租和水電，**請改成實際的金額和日期**）：

| 名稱 | 金額 | 分類 | 扣款日 | 每幾個月 | 下次扣款日 | 啟用 |
|---|---|---|---|---|---|---|
| 房租 | 15000 | 其他 | 5 | 1 | 2026-11-05 | 是 |
| 水電 | | 其他 | 20 | 2 | 2026-10-20 | 是 |

- **金額有填**：到了扣款日自動記帳，記錄人顯示「🔁 固定支出」。
- **金額空白**（例如每期不同的水電費）：扣款日只提醒，繳費後再傳「水電 1850」記帳。
- **扣款前一天**會在家庭群組提醒。
- 台灣的水電費大多兩個月一期，所以水電預設「每幾個月」是 2。
- 「下次扣款日」會自動往後推；暫停某一項就把「啟用」改成「否」。

提醒會推播到**機器人所在的家庭群組**（機器人加入群組或在群組收到第一則訊息時自動記住）。推播會用到 LINE 官方帳號每月 200 則的免費額度，固定支出一個月大約只用幾則。

## 自訂關鍵字

在 LINE 直接傳指令就可以管理（不經過 AI）：

- `關鍵字 健身房 醫療` 或 `健身房 歸類到 醫療`：新增或更新
- `關鍵字 刪除 健身房`：刪除
- `關鍵字`：看目前的自訂關鍵字

開了 AI 也一樣：AI 判斷的分類會以自訂關鍵字為準。

也可以直接改試算表的「關鍵字」工作表，A 欄填關鍵字、B 欄填分類（必須是餐飲、交通、日用品、醫療、育兒、其他其中之一）：

| 關鍵字 | 分類 |
|---|---|
| 菜市場 | 餐飲 |
| 好市多 | 餐飲 |

品項裡**包含**關鍵字就會套用，自訂的優先於內建的。不用重新部署，下一筆記帳就會生效。

## 注意事項

- **Webhook 網址請勿公開**：Apps Script 讀不到 LINE 的簽章標頭，無法驗證請求來源。有設定 `LINE_BOT_USER_ID` 可以擋掉一部分錯誤的請求。
- **在群組中**，機器人只回應記帳和查詢，不會回應閒聊。金額要放在最後（`午餐 120`），像「我 3 點到」這種句子不會被誤記。
- **記錄人**會自動抓 LINE 顯示名稱。
- 試算表可以直接修改。改分類、金額都沒問題，查詢會以試算表的內容為準。

## 自動部署（選用）

設定好之後，GitHub 上的程式碼**合併到 `main` 就會自動更新 Apps Script 並重新部署**，網址不變，不用再複製貼上。以下是一次性的設定：

### 1. 開啟 Apps Script API

打開 <https://script.google.com/home/usersettings>，把「Google Apps Script API」切換成**開啟**。

### 2. 取得 clasp 授權（`.clasprc.json`）

**有電腦（已安裝 Node.js）：**

```bash
npx @google/clasp@3.4.1 login
```

瀏覽器會開啟 Google 登入，選你的帳號並允許。完成後，授權檔在：
- Mac：`~/.clasprc.json`（終端機執行 `cat ~/.clasprc.json` 顯示內容）
- Windows：`C:\Users\你的名字\.clasprc.json`（用記事本打開）

**只有 iPad：用 GitHub Codespaces（瀏覽器裡的電腦）**

1. 在本專案 GitHub 頁面按綠色 **Code → Codespaces → Create codespace on main**。
2. 下方終端機輸入：`npx @google/clasp@3.4.1 login --no-localhost`
3. 打開它顯示的網址，選你的帳號並允許。
4. 最後瀏覽器會跳到一個**打不開的 localhost 網頁，這是正常的**。把網址列的**完整網址**複製起來，貼回終端機按 Enter。
5. 輸入 `cat ~/.clasprc.json`，複製顯示的全部內容。
6. 完成後到 <https://github.com/codespaces> 把這個 Codespace 刪掉。

### 3. 找到兩個 ID

- **指令碼 ID**：Apps Script 左側 **⚙️ 專案設定 → 指令碼 ID**。
- **部署作業 ID**：**部署 → 管理部署作業**，選目前的網頁應用程式，複製「部署作業 ID」。它也是網頁應用程式網址中 `/s/` 和 `/exec` 之間的那一段。

### 4. 存到 GitHub Secrets

GitHub 專案頁面 **Settings → Secrets and variables → Actions → New repository secret**，新增三個：

| Name | Secret |
|---|---|
| `CLASPRC_JSON` | 第 2 步 `.clasprc.json` 的完整內容 |
| `SCRIPT_ID` | 指令碼 ID |
| `DEPLOYMENT_ID` | 部署作業 ID |

### 5. 測試

GitHub 專案頁面 **Actions → 部署到 Apps Script → Run workflow**。跑完是綠色勾勾，就代表 Apps Script 已更新。第一次自動部署後，Apps Script 裡的檔案會變成 `家庭記帳.gs`，原本的 `程式碼.gs` 會被取代，這是正常的。

### 注意

- `CLASPRC_JSON` 可以修改你 Google 帳號裡**所有** Apps Script 專案，**只能放在 GitHub Secrets**，不要貼到其他地方。不想用了可以到 <https://myaccount.google.com/permissions> 移除「clasp」的存取權。
- 如果新功能需要新的權限（例如第一次加入每日排程），自動部署後還是要到 Apps Script **手動執行一次 `setup`** 完成授權。需要時我會特別提醒。
- 自動部署只會部署 `main`。PR 上會自動跑測試，但不會部署。

## 進階：改用 AI 解析（選用）

設定 AI 金鑰後，可以隨口說（`昨天全聯買衛生紙花了 560`）、拍收據照片記帳，也能用自然語句查詢。在「指令碼屬性」新增其中一個即可，不用重新部署：

| 屬性 | 說明 |
|---|---|
| `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/) 免費申請。有每日使用次數上限；免費方案的內容可能被 Google 用來改善產品 |
| `ANTHROPIC_API_KEY` | [Claude Console](https://platform.claude.com/) 申請，需儲值，約每月 NT$3 |
| `AI_PROVIDER` | （選填）`rules`、`gemini` 或 `claude`，強制指定解析方式 |
| `GEMINI_MODEL` | （選填）Gemini 模型名稱，預設 `gemini-flash-latest` |

AI 忙線（例如 Gemini 回 503「high demand」）或額度用完時，會自動重試兩次；仍然失敗的話，文字訊息改用免費的規則辨識，`午餐 120` 這類格式照樣能記帳，照片則請家人稍後再傳。如果常常忙線，可以在 `GEMINI_MODEL` 改用其他模型。

## 開發

程式原始檔在 `gas/`，`dist/家庭記帳.gs` 是合併後的單一檔案。修改 `gas/` 後要重新產生：

```bash
node scripts/bundle.js   # 產生 dist/家庭記帳.gs
node test/run.js         # 用模擬的 Apps Script 環境測試，不需要任何金鑰
```
