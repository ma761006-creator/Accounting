# 家庭記帳 LINE 機器人

把機器人加進家人的 LINE 群組，傳「午餐 120」就會自動記到 Google 試算表。**完全免費，不用申請任何 AI 金鑰。**

- **記帳**：`品項 金額`，例如 `午餐 120`、`全聯 560`、`7-11 85`、`中油 1200`
  - 前面加日期：`昨天 加油 1200`、`10/8 全聯 560`
  - 最後加分類可指定分類：`掛號 150 醫療`
  - 一次記多筆：`加油 1200、停車 60`
- **查詢**：`今天`、`本週`、`本月`、`上月`、`今年`，可加分類，例如 `本月 餐飲`
- **刪除**：傳 `刪除`，會撤銷自己最近一次記的帳
- **說明**：傳 `說明`
- **分類**：餐飲、交通、日用品、醫療，以及其他（在 `gas/Config.gs` 修改）

分類是用**關鍵字**判斷的，例如「全聯」→ 日用品、「7-11」→ 餐飲、「中油」→ 交通。判斷不出來的歸到「其他」，也可以在試算表的「關鍵字」工作表自己新增。

架構：LINE → Google Apps Script → Google 試算表，全部免費。

## 設定步驟（約 30 分鐘，建議用電腦）

### 1. 建立 LINE 機器人

LINE 現在不能直接在 LINE Developers 建立 Messaging API channel，要**先建立官方帳號，再啟用 Messaging API**。

1. **建立 LINE 官方帳號**：到 [LINE Official Account Manager](https://manager.line.biz/) 用 LINE 帳號登入，按「建立 LINE 官方帳號」填寫表單（名稱例如「家庭記帳」；業種隨意選，例如「個人」）。
2. **啟用 Messaging API**：在官方帳號後台右上角 **設定 → Messaging API → 啟用 Messaging API**。手機版後台可能沒有這個選項，請用電腦，或在瀏覽器選單選「要求電腦版網站」。
   - 選擇或建立一個 **Provider**（例如「我的家」）。Provider 選定後**不能更改**。
   - 隱私權政策、服務條款網址可以留空，按確定。
3. **調整回應設定**：同一個後台的 **設定 → 回應設定**：
   - **聊天**：關閉
   - **自動回應訊息**：關閉
   - **Webhook**：開啟
4. **允許加入群組**：**設定 → 帳號設定 → 功能切換**，把「加入群組或多人聊天室」改成允許。
5. **取得權杖**：到 [LINE Developers](https://developers.line.biz/console/) 用同一個 LINE 帳號登入，點剛剛的 Provider，再點官方帳號對應的 channel：
   - **Messaging API** 分頁最下方 **Channel access token (long-lived)** 按 **Issue**，複製權杖。權杖等同密碼，不要給別人看。
   - 同一頁掃 QR code，把機器人加為好友。
6. （選填）在 **Basic settings** 分頁最下方複製 **Your user ID**（U 開頭），第 2 步會用到。

### 2. 建立試算表和 Apps Script

1. 開一個新的 [Google 試算表](https://sheets.new)，命名為「家庭帳本」。
2. 選單 **擴充功能 → Apps Script**。
3. 打開本專案的 [`dist/家庭記帳.gs`](dist/家庭記帳.gs)，按右上角的複製按鈕複製全部內容。
4. 回到 Apps Script 編輯器，把預設檔案 `程式碼.gs` 的內容**全部刪掉**，貼上剛剛複製的內容，按 💾 儲存。
5. 「專案設定（齒輪）→ 指令碼屬性」新增：

   | 屬性 | 值 |
   |---|---|
   | `LINE_CHANNEL_ACCESS_TOKEN` | 第 1 步的 Channel access token（一整串，中間不能有空格） |
   | `LINE_BOT_USER_ID` | （選填）第 1 步的 Your user ID |

6. 回到編輯器，上方函式選 `setup`，按 **執行**，依指示授權（會出現「Google 尚未驗證這個應用程式」，按「進階 → 前往（不安全）」，這是你自己的程式所以沒關係）。試算表會多出「帳本」和「關鍵字」兩個工作表。

### 3. 部署並連上 LINE

1. Apps Script 右上角 **部署 → 新增部署作業**，齒輪選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
2. 部署後複製 **網頁應用程式網址**（`https://script.google.com/macros/s/.../exec`）。
3. 回到 LINE Developers 的 **Messaging API** 分頁：
   - **Webhook URL** 貼上網址，按 Update
   - 打開 **Use webhook**
   - 按 Verify 有時會顯示 302 錯誤，這是 Apps Script 的轉址造成的，**不影響實際使用**
4. 私訊機器人 `午餐 120` 測試。成功後把機器人邀進家庭群組。

> ⚠️ **之後更新程式碼**，要到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」，網址不會變。

## 自訂關鍵字

試算表的「關鍵字」工作表，A 欄填關鍵字、B 欄填分類（必須是餐飲、交通、日用品、醫療、其他其中之一）：

| 關鍵字 | 分類 |
|---|---|
| 菜市場 | 餐飲 |
| 好市多 | 餐飲 |

品項裡**包含**關鍵字就會套用，自訂的優先於內建的。不用重新部署，下一筆記帳就會生效。

## 注意事項

- **Webhook 網址請勿公開**：Apps Script 讀不到 LINE 的簽章標頭，無法驗證請求來源。有設定 `LINE_BOT_USER_ID` 可以擋掉一部分錯誤的請求。
- **在群組中**，機器人只回應記帳和查詢，不會回應閒聊。金額要放在最後（`午餐 120`），像「我 3 點到」這種句子不會被誤記。
- **記錄人**會自動抓 LINE 顯示名稱。
- 試算表可以直接修改。改分類、金額都沒問題，查詢會以試算表的內容為準。

## 進階：改用 AI 解析（選用）

設定 AI 金鑰後，可以隨口說（`昨天全聯買衛生紙花了 560`）、拍收據照片記帳，也能用自然語句查詢。在「指令碼屬性」新增其中一個即可，不用重新部署：

| 屬性 | 說明 |
|---|---|
| `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/) 免費申請。有每日使用次數上限；免費方案的內容可能被 Google 用來改善產品 |
| `ANTHROPIC_API_KEY` | [Claude Console](https://platform.claude.com/) 申請，需儲值，約每月 NT$3 |
| `AI_PROVIDER` | （選填）`rules`、`gemini` 或 `claude`，強制指定解析方式 |
| `GEMINI_MODEL` | （選填）Gemini 模型名稱，預設 `gemini-flash-latest` |

## 開發

程式原始檔在 `gas/`，`dist/家庭記帳.gs` 是合併後的單一檔案。修改 `gas/` 後要重新產生：

```bash
node scripts/bundle.js   # 產生 dist/家庭記帳.gs
node test/run.js         # 用模擬的 Apps Script 環境測試，不需要任何金鑰
```
